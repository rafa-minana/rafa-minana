## 📦 Open Source

### 🔷 [ts-useful-types](https://github.com/rafa-minana/ts-useful-types)

A collection of generic TypeScript utility types to improve type safety and reduce boilerplate in any TS project — Angular, Node or anything else.

> `Nullable<T>` · `Optional<T>` · `DeepPartial<T>` · `KeysOf<T>` · and more...

```ts
import { Nullable, DeepPartial } from 'ts-useful-types';

type User = { name: string; address: { city: string } };
type PartialUser = DeepPartial<User>; // All nested fields optional
type MaybeUser = Nullable<User>;      // User | null
```

📦 [Available on npm](https://www.npmjs.com/package/ts-useful-types)
