## 📦 Open Source

### 🔷 [ts-useful-types](https://github.com/cotaByte/ts-useful-types)
A TypeScript utility library with a collection of useful generic types to improve type safety and reduce boilerplate in your projects. Built for developers who want to write more expressive and robust TypeScript — whether in Angular, Node, or any TS-based project.

> `Nullable<T>` · `Optional<T>` · `DeepPartial<T>` · `KeysOf<T>` · and more...

```ts
// Example usage
import { Nullable, DeepPartial } from 'ts-useful-types';

type User = { name: string; address: { city: string } };
type PartialUser = DeepPartial<User>; // All nested fields optional
type MaybeUser = Nullable<User>;      // User | null
```
[npm](https://www.npmjs.com/package/ts-useful-types)
